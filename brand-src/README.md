# Brand masters

Source files for the Sypher Solutions identity (compass and ribbon, October 2026) and the principal's headshot. The site never loads these directly; web sizes are generated into `assets/img/`.

| Master | Web files | Used for |
| --- | --- | --- |
| `logo-package/01_High_Resolution_PNG/02_Primary_Stacked_Metallic.png` | `sypher-mark.webp` (900w), `sypher-mark-480.webp`, `sypher-mark-sm.webp` (the emblem, cut above the wordmark) | Hero, puzzle centre piece, header and footer icon, watermarks, proposal and client-room covers |
| same | `logo-stacked.webp` (520w) | Client portal sign-in |
| same, cropped | `ribbon-portrait.webp` | Backdrop behind the closing band and the portal sign-in |
| `logo-package/02_Web_Icons/Sypher_Monogram_1024.png` | `favicon.ico`, `favicon-48.png`, `monogram-512.png`; on navy: `apple-touch-icon.png`, `icon-192.png`, `icon-512-maskable.png` | Browser tabs, home screens, structured data |
| `photography/michael-furth-headshot.jpg` | `michael-furth.webp` (800w), `michael-furth-480.webp`, `michael-furth-avatar.webp` (192px face crop) | About and homepage portraits, client room, proposal letter, essay bylines |

Notes
- The horizontal lockup isn't used in the site header: at header height its "SOLUTIONS" line would render about 3px tall. The header pairs the emblem with the wordmark set in type, finished in the logo's brushed gold.
- The one-colour navy logo is for light backgrounds and print only.
- The package is raster PNG. Ask the designer for SVG or PDF vectors for print, signage and embroidery.
